Comment utiliser le formulaire
Opérations PDF ?

Ce guide explique pas à pas comment préparer et envoyer un dossier de fabrication. Pas besoin d'être technique — c'est rapide.

1
Entrer le numéro d'OF

En haut du formulaire, il y a un champ Numéro OF. C'est le numéro de l'ordre de fabrication que tu traites.

Exemple : 12344 ou 43erf

💡 Le numéro OF est celui du bon de commande ou du dossier client. Si tu as un doute, vérifie dans l'ERP ou demande à ton responsable.
🔄 Si un dossier avec ce numéro d'OF existe déjà dans Dropbox, le système ajoute automatiquement un suffixe (A, B, C…) pour éviter les conflits. Par exemple : 12344A.
2
Ajouter les pièces

Dans le tableau Détails des pièces, chaque ligne correspond à une pièce de l'OF. Remplis les colonnes :

  • ID — le numéro de référence de la pièce (chiffres uniquement, ex : 13340)
  • Matériel — la matière utilisée (ex : Acier inox 316L)
  • Quantité — le nombre de pièces à fabriquer
  • Traitement — l'opération principale (ex : Tournage, Fraisage)
  • Commentaire — toute info utile, optionnel (tolérance, finition, remarque…)

Pour ajouter une deuxième pièce, clique sur + Ajouter une pièce. Tu peux en ajouter autant que nécessaire.

💡 Pour supprimer une ligne, clique sur le × à droite de la ligne.
3
Envoyer le formulaire

Une fois tout rempli, clique sur le bouton Envoyer.

Le système va :

  • Rechercher les PDFs techniques et les fichiers STEP dans Dropbox
  • Anonymiser automatiquement les plans PDF (suppression des infos confidentielles)
  • Anonymiser les fichiers STEP (suppression des métadonnées propriétaires : auteur, organisation…)
  • Générer la demande de devis en PDF et en Word (.docx)
  • Créer la structure de dossiers dans Dropbox : NM{OF} (plans anonymisés) et DP{OF} (devis + STEP)
  • Tout regrouper dans un dossier ZIP prêt à l'envoi
⏳ Le traitement prend environ 30 à 60 secondes. Ne ferme pas la page pendant ce temps. Un message "Envoi en cours…" s'affiche pendant que ça tourne.
4
Valider les plans anonymisés

Après le traitement, l'écran de validation des plans s'affiche. Chaque page est présentée en comparaison côte à côte : l'original à gauche, la version anonymisée à droite.

Pour chaque page, tu as trois options :

  • ✓ Accepter — la page est correctement anonymisée, tu valides
  • ✗ Corriger — ouvre le mode correction IA : dessine des zones rouges sur le plan, ajoute un prompt textuel optionnel, et l'IA analyse et masque les informations restantes. L'IA peut aussi suggérer des zones supplémentaires à corriger.
  • + Table USI-PRO — ajoute un cartouche USI-PRO sur le plan. Tu peux remplir les champs optionnels (Désignation, Matière, Norme, Finition), puis glisser-déposer le cartouche où tu veux sur le plan et le redimensionner avec les poignées sur les coins et bords.

Un compteur en haut indique ta progression (ex : 3 / 5 pages validées). Utilise les boutons Précédent et Suivant pour naviguer entre les pages.

💡 En mode Corriger, tu peux dessiner plusieurs zones rouges sur le plan, ajouter un prompt de description, puis cliquer sur "Appliquer les corrections". L'IA analyse et masque les zones sélectionnées.
⚠️ Toutes les pages doivent être validées avant de pouvoir passer à l'étape suivante. Le système avance automatiquement vers la prochaine page non validée.
5
Récupérer le résultat

Une fois toutes les pages validées, le système finalise le dossier et l'uploade sur Dropbox. L'écran de résultat s'affiche avec deux parties :

À gauche — Visionneuse PDF : Un viewer interactif affiche les PDFs anonymisés. Utilise les boutons ← Précédent et Suivant → pour naviguer entre les fichiers, avec un compteur (ex : 2 / 4) et le nom du fichier affiché. Chaque page du PDF est rendue en haute résolution.

À droite — Récapitulatif :

  • Un indicateur de succès ✓ confirme que le dossier a été traité
  • Les boutons d'action : Ouvrir dans Dropbox et Télécharger le ZIP
  • L'arborescence du dossier générée
  • Les chips de pièces : en vert les pièces trouvées, en orange les pièces non trouvées dans Dropbox
Structure du dossier généré
OF12344/  DIR  Dossier racine
NM12344.zip  ✓ Anonymisé & Validé
13340.pdf  PDF  Plan anonymisé
13342.pdf  PDF  Plan anonymisé
DP12344/  DIR  Plans & Fichiers STEP
12344.pdf  PDF  Demande de devis
12344.docx  DOCX  Demande de devis
💡 NM = dossier des plans anonymisés (Non Marqués). DP = dossier contenant la demande de devis (PDF + Word) et les fichiers STEP anonymisés.
💡 Pour faire un nouvel OF, clique sur ← Retour au formulaire en haut à gauche. Tes données précédentes sont encore là si tu veux les modifier.
Questions fréquentes
Une pièce n'apparaît pas dans le résultat, c'est normal ?
Ça veut dire que le PDF de cette pièce n'a pas été trouvé dans Dropbox. Vérifie que le PDF est bien déposé dans le bon dossier Dropbox avec le bon nom de fichier (ex : 13340.pdf). Les pièces non trouvées apparaissent en orange dans la section "Pièces traitées".
Le traitement tourne depuis longtemps, que faire ?
Si ça dépasse 2 minutes sans réponse, actualise la page et recommence. Si le problème persiste, contacte le support technique.
Est-ce que je peux mettre plusieurs pièces avec le même ID ?
Non, chaque pièce doit avoir un ID unique. Si tu as deux références identiques avec des variantes, ajoute-les comme deux lignes séparées avec des IDs distincts.
Où va le dossier dans Dropbox ?
Le dossier est créé automatiquement dans Dropbox avec la structure OF{numéro}/, contenant un sous-dossier NM (plans anonymisés) et DP (devis + STEP). Le bouton "Ouvrir dans Dropbox" t'amène directement dessus.
Les fichiers STEP sont-ils aussi anonymisés ?
Oui. Les fichiers STEP (format ISO 10303-21) sont automatiquement anonymisés : les métadonnées propriétaires (auteur, organisation, autorisation) sont supprimées dans l'en-tête. La géométrie (section DATA) n'est jamais modifiée. Les fichiers anonymisés sont placés dans le dossier DP.
Un numéro OF avec suffixe (ex: 12344A), c'est quoi ?
Si le dossier OF12344 existe déjà dans Dropbox, le système crée automatiquement OF12344A, puis OF12344B, etc. Cela évite d'écraser un dossier existant.
Le PDF est illisible ou trop petit dans le viewer ?
Les plans sont affichés en haute résolution dans l'écran de validation. Si le détail ne suffit pas, utilise le mode Corriger qui affiche le plan en plein écran. Tu peux aussi télécharger le ZIP et ouvrir le PDF directement sur ton ordinateur.
Comment fonctionne le mode correction IA ?
Dans le mode Corriger, dessine des rectangles rouges sur les zones où l'anonymisation est incomplète. Tu peux ajouter un prompt textuel pour guider l'IA. L'IA analyse les zones et applique des masques blancs pour couvrir les informations restantes. Après correction, tu peux valider la page ou recommencer.
